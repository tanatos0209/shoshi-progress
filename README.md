# 進捗管理（司法書士試験）

司法書士試験に向けた学習進捗の PWA です。ホームからテキストまとめ・択一対策・スピードチェックへ進みます。

公開URLの想定は https://tanatos0209.github.io/shoshi-progress/ です。択一アプリ（https://tanatos0209.github.io/shoshi-ox/ ）や、以前進捗を載せてしまった総合アプリ（https://tanatos0209.github.io/shoshi-sogo/ ）とは別のアドレスです。

## パス

配信パスは `/shoshi-progress/` です。HTML・CSS・JS・画像・manifest・Service Worker は相対パスです。`manifest` の `start_url` と `scope` は `./`、キャッシュ名は `shoshi-progress-v10` です。

## GitHub Pages

**Settings → Pages → Build and deployment → Deploy from a branch → Branch: `main` / Folder: `/ (root)`**

`main` に載ると https://tanatos0209.github.io/shoshi-progress/ に出ます。このリポジトリには `.nojekyll` を置いてあります。

## 画面

- **ホーム** … 本試験の日付と残日数（`本試験　YYYY年M月D日　あとN日`）、今日の学習時間、連続日数、今週のグラフ、今日の進捗、科目別進捗。試験日はアジア/東京の「次の7月最初の日曜日」です。試験当日はあと0日、その翌日に次年へ移ります。ホームの緑と金の並びはそのままです。
- **今日の進捗** … 総合％は、内訳5種（テキスト・問題集・テキストまとめ・択一対策・スピードチェック）の均等平均です（重み付けなし）。0%の行も平均に入ります。たとえば 0 / 0 / 100 / 100 / 100 なら 60% です。内訳は上から テキスト、問題集、テキストまとめ、択一対策、スピードチェック。行を押すと、その画面へ進みます。テキストは読んだページ ÷ 今日のページ数です。問題集は準備中のまま 0% で、平均には入ります。総合％の上に問数の行は出しません。
- **科目別進捗** … 開閉します。開いた直後は閉じています。
- **連続日数** … その日の記録が30分以上になったときだけ +1。アプリを開いただけでは増えません。当日がまだ30分未満でも、前日までが続いていればその連続は残ります。
- **今日の学習を開始** … 「今日の課題」で5項目を上の順に出します。「はじめる」で1番から案内します。テキストは今日の範囲（見本は不動産登記法Ⅰ p.1–19）をスライダーで記録します。「この範囲を読んだ」は今のバー位置の仮確定で、あとから動かせます。ページ数がテキストの％になります。問題集は短い準備中画面のままです。テキストまとめは空欄をタップで表示・再タップで隠し、わかった／わからないで1枚ずつ進みます。択一は shoshi-ox を `https://tanatos0209.github.io/shoshi-ox/?from=progress&start=today&scope=review` で開きます（今日の学習を開始のあと復習待ち）。開いたまま「この1問を終えた」で1問ずつ数えます。スピードチェックは要点の空欄と「ここから出題する」から○×です。終わった分だけ内訳と総合％が上がり、一括では100%になりません。途中でやめると、次は残りから再開します。
- **テキスト** … ホームの内訳と「今日の学習を開始」から開きます。見出しは本のアイコンと「テキスト」「Vマジック」、右に「AIサポート」。今日のノルマは1行だけ（科目の前に巻数の数字は付けません）。今日の範囲はページ幅だけです。バーの下は「読んだページ/今日のページ」。計測中の小さな表示は、ほかの学習画面と同じです。
- **AIサポート** … テキストから開きます。画像とメモの枠が20個です。この端末の localStorage（キー `shoshi-progress-ai-v1`）に残り、AIの返答はまだありません。戻るとテキストです。
- **テキストまとめ** **択一対策** **スピードチェック** … 試験カードの3つの入口はこれまでどおりです。「学習を始めますか？」のあと、その学習画面へ進みます。計測は画面右上の `計測中 MM:SS` です。テキストまとめは民法総則の見本（出典の初期値はVマジック、未成年者だけ合格ゾーンテキスト）。スピードチェックは第1章 総則 / 自然人の能力ほかの見本です。択一対策は https://tanatos0209.github.io/shoshi-ox/ をその画面の中で開きます。平日A・週末B+Cの出し分けはまだ入れていません。
- **わからない** … 明日の復習順だけを前にします。今日の％の計算は変えません。
- **前日の達成** … 学習を始めた日の達成率をその日の記録に残し、翌日の新規数・択一の問数・スピードの論点数を±1だけ動かします。
- **パーフェクトコントロール** **カレンダー** … 準備中。
- **記録する** … 今日の学習時間、解いた問題数、メイン／マイナー科目の択一・記述を手入力します。問題数は択一の今日の問数として総合％に入ります。計測で溜まった時間も同じ記録に足します。この端末の localStorage（キー `shoshi-progress-v1`）に、今日の分数・今週のグラフ・連続日数・試験日・SRSを保存します。
- **設定** … 週の目標時間、1日の目標問題数（択一の基準問数）。1日の勉強時間の目標は4時間で固定です。試験日は自動で、設定画面にはその日付だけ出します。ホームの今日の学習時間は、1分未満を切り捨てて表示します。今週の合計と棒グラフは、毎週月曜 0:00（アジア/東京）からその日曜までです。月曜を過ぎると前週は今週の表示から外れます。日ごとの記録は残ります。

## ローカル確認

リポジトリのルートで:

```bash
python3 -m http.server 4173
```

ブラウザで http://127.0.0.1:4173/ を開きます。

GitHub Pages と同じ `/shoshi-progress/` で確認する場合は、ひとつ上のディレクトリからこのフォルダを配信します。

```bash
cd ..
python3 -m http.server 4173
```

ブラウザで http://127.0.0.1:4173/shoshi-progress/ を開きます。

日付・連続・タイマーのルールは `node --test test/rules.test.js`、今日の％と課題の順番は `node --test test/pcs.test.js` で確認できます。
